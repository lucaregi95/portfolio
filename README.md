# Portfolio BTS SIO SLAM

Site statique (HTML/CSS/JS), compatible GitHub Pages.

## À personnaliser
- `data/config.json` : nom, école, disponibilité, e-mail, LinkedIn, GitHub
- `data/projets.json` : contenu des fiches projet
- `data/competences.json` : lien entre compétences et projets (liste de slugs)
- `data/veille.json` : méthode, sujets, articles
- `assets/img/projets/` : captures (inclusion.png, cinema.png, ecole.png)
- `assets/docs/cv.pdf` : votre CV
- `contact.html` : remplacer `VOTRE_ID` dans l'action du formulaire par votre identifiant Formspree

## Test en local
Utiliser l'extension Live Server de VS Code (fetch() ne marche pas en double-clic).

## Publication
Settings → Pages → Deploy from a branch → main / (root).
